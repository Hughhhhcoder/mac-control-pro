## Mac Control Pro 0.1.0

首个开源预览版：原生 SwiftUI 监控界面、温度与风扇读数、会话图表、风扇曲线与预设、菜单栏、中文 / English 偏好设置，以及 JSON 诊断导出。

提供 Apple Silicon + Intel 通用 DMG、ZIP 和 SHA-256。完整源码采用 MIT License，包含测试、构建脚本、CI 和发布工作流。

### 安装

下载 DMG，把应用拖入 Applications。首发使用 ad-hoc 签名，尚未 Apple 公证；首次启动可能需要在系统设置的隐私与安全性中选择「仍要打开」。监控无需管理员权限。

风扇写入需要另外安装源码仓库内的控制助手；详见 README。助手带短租约与高温恢复逻辑，SMC 兼容性仍需逐机验证。

### 已知边界

- SMC 接口未公开，传感器及可控风扇取决于机型与系统版本。
- 没有覆盖全部 Intel / Apple Silicon 机型的硬件写入验证。
- 无风扇机型正常显示无可控风扇；不支持的数据明确显示不可用。
- 图表为当前会话数据，演示模式明确标注模拟值。
- 本项目独立实现，不包含 Macs Fan Control 的商业代码、二进制或资源。

### 已执行的只读实机检查

在 Mac18,1 / Apple M6 / macOS 27.0 上，真实诊断采样读到 145 个温度传感器与 1 个风扇，包含实际 RPM、硬件范围与自动模式。未安装控制助手，未进行特权风扇写入；Intel 和其他机型仍待实机验证。

发布检查范围与最新兼容性记录请见仓库文档。欢迎提交可重复的机型报告。
