## Mac Control Pro 0.2.0

### 安装与跨机型处理

- 新增完整通用 PKG，一次安装应用与匹配助手；DMG 内也包含该安装器。
- 应用设置自带助手安装、更新与卸载入口，使用 macOS 原生安装器和本机登录账户，无固定 UID、源码或终端依赖。
- 按实际能力识别各只风扇，区分无风扇、读取失败、只读和可控制状态。补齐双风扇独立控制、受保护模式处理及桌面低转速范围路径。
- 内置预设改为风扇范围百分比，适配 MacBook Pro、Mac mini / Mac Studio 等不同转速范围；自定义配置保留绝对 RPM，并兼容 schema 1。

### 控制状态与恢复

- P2 协议绑定会话所有权，分离新控制、续约、会话释放与用户明确恢复自动；旧助手须升级后才能控制。
- 等待助手或固件时显示处理中；目标完成有期限回读后，核心与助手都在最终风扇快照中核对手动模式和目标转速，二者同时匹配才标记已应用。续约同样检查确认结果，失败不重放旧目标；已应用不等于实际 RPM 已稳定。
- 租约失效时优先显示同次响应的高温等恢复原因，旧恢复信息不会覆盖无关的新错误；过期状态快照不能撤销新策略，当前安全恢复仍会终止原策略。
- 85 项 XCTest 全部通过，覆盖多风扇、延迟读回、受保护状态、失联、配置迁移和界面异步状态；助手与 CLI 自检、通用构建及安装包结构检查通过。

### 验证范围

0.2.0 同版助手与 CLI 在 Mac18,1 / Apple M6 / macOS 27.0 上完成四项复核：

- 固定 5500 RPM：最后 5 个手动样本平均 5504 RPM，最大目标误差 13 RPM。
- 温度曲线：请求目标约 5875–6253 RPM，结束后恢复自动、租约为空。
- 竞争会话：6000 RPM 请求被拒绝、exit 1，原 5500 RPM 会话继续。
- SIGKILL：独立采样在客户端结束后约 12.129 秒观察到模式 0，最终租约为空。

GUI 当前仅确认 86°C 高温保护，未记录 0.2.0 GUI 固定转速或曲线成功。0.1.1 的历史实测单独保留。

M4 Pro、Mac mini、Mac Studio、其他 Mac 与 Intel 的新增控制路径由模拟传输和自动化测试覆盖，**不宣称所有 2022 年以来的 Mac 已实测通过**。
