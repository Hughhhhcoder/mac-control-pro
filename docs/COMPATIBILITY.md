# 兼容性与验证范围

## 平台

| 项目 | 预期支持 | 边界 |
| --- | --- | --- |
| 系统 | macOS 14 或更新 | 当前实机为 macOS 27.0；最低部署目标不等于 macOS 14 实机验证 |
| CPU 架构 | Apple Silicon arm64、Intel x86_64 | 通用二进制构建不等于两类硬件均已实机验证 |
| CPU / 内存 / 运行时间 | 系统公开统计接口 | CPU 第一次采样可能暂不可用 |
| 电池与供电 | 有电池的 Mac | 台式机不虚构电池数值 |
| 系统热状态 | `ProcessInfo.thermalState` | 系统状态枚举，不是摄氏温度 |
| 温度传感器 | 可读取的 SMC key | 芯片、固件和系统版本可能改变可读范围及含义；通用 key 不保证对应独立物理传感器 |
| 风扇读取 | SMC 提供的风扇 | 无风扇的 MacBook Air 正常显示无可控风扇 |
| 手动转速 / 曲线 | 助手安装后、SMC 写入被硬件接受时 | M6 本机已实测；其他机型可能拒绝写入或需要不同控制时序 |

## 已记录的实机验证

| 版本 / 日期 | 硬件 / 系统 | 实际结果 | 未验证 |
| --- | --- | --- | --- |
| 0.1.0 / 2026-11-16 | Mac18,1 · Apple M6 · macOS 27.0 | 发布时仅进行只读检查：145 个温度 key、1 个风扇，有实际 RPM、最小 / 最大范围和自动模式读数 | 当时未安装助手，未执行风扇写入 |
| 0.1.1 / 2026-11-16 | Mac18,1 · Apple M6 · macOS 27.0 | 已安装助手；固定 3000 RPM 达到实际 3001 RPM，5500 RPM 稳定后为 5490–5505 RPM；原生界面 4500 RPM 连续约 20 秒，曲线预设约 24 秒；CLI 12 秒温度曲线正常结束；明确恢复、85°C 保护与客户端丢失后的租约回退均有真实读回 | 3000 / 5500 RPM 测试被高温保护中断；4500 RPM 的约 20 秒观察不构成长时稳定性保证。Intel、其他 Mac 型号与 macOS 14 实机运行未验证 |

[硬件验证记录](HARDWARE_VALIDATION.md) 包含逐次数据与时间图。传感器数量和具体转速会随固件及采样状态变化，单台机器的成功结果不构成所有 Mac 的控制保证。28 项自动化测试覆盖核心、助手与 CLI 参数逻辑，不能替代其他机型的硬件测试。

SMC 没有面向第三方的稳定公开协议。未知或失败的读取返回不可用；正常模式不混入演示值。管理员权限及代码签名不能使固件不支持的操作变得可用。

## 控制保护的边界

- 固定转速限制在 SMC 报告范围内，并具有至少 1200 RPM 的软件下限；零转速、异常范围和不存在的风扇不能作为有效目标。
- 目标写入使用最多 0.8 秒的单调时钟确认，避免读回旧目标时过早误判；失败仍请求自动恢复。目标寄存器确认与实际风扇转速收敛是两件事，后者必须独立观察。
- 助手维护约 12 秒租约。M6 失联实测在客户端被强制结束后的 12.131 秒观察到自动模式；此值不是所有负载及故障条件下的恢复时限保证。
- 传感器无法验证或任何受保护读数达到 85°C 时，助手拒绝或结束手动控制。M6 固定转速实测已触发此路径。客户端检测租约终止后停止该次会话，不自动重新申请旧目标。
- 助手写入前保存所控制的风扇 ID；launchd 重启后尝试恢复，成功后更新日志。卸载若有未恢复记录会保留文件并退出。崩溃日志恢复代码存在，不等于所有助手崩溃、睡眠或内核阻塞路径均已实测。
- 退出、卸载和超时恢复须由 SMC / 固件接受。断电、系统挂起或内核调用阻塞可能影响时间与结果。
- 同一风扇不要由多个控制器持续发送不同目标。使用另一工具前先恢复自动并停用本项目的控制会话。

报告包含 Mac 型号、芯片、macOS 与应用版本，以及助手安装状态。诊断与采样应保留实际读回和恢复结果，分享前移除序列号、账号、UUID 及无关系统信息。经可重复实测后再扩展已验证矩阵。
