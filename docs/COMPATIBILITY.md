# 兼容性与验证范围

## 平台

| 项目 | 预期支持 | 边界 |
| --- | --- | --- |
| 系统 | macOS 14 或更新 | 发布构建与运行验证见具体 Release |
| CPU 架构 | Apple Silicon arm64、Intel x86_64 | 通用二进制构建不等于两类硬件均已实机验证 |
| CPU / 内存 / 运行时间 | 系统公开统计接口 | CPU 第一次采样可能暂不可用 |
| 电池与供电 | 有电池的 Mac | 台式机不虚构电池数值 |
| 系统热状态 | `ProcessInfo.thermalState` | 这是系统状态枚举，不是摄氏温度 |
| 温度传感器 | 可读取的已知 SMC key | 不同芯片、固件和系统版本可能返回不同结果 |
| 风扇读取 | SMC 提供的风扇 | 无风扇的 MacBook Air 正常显示无可控风扇 |
| 手动转速 / 曲线 | 助手安装后、SMC 写入被硬件接受时 | 某些机型拒绝写入或需要不同的控制 key |

## 首发的实际保证

核心解析、曲线和助手逻辑由自动化测试覆盖，发布包还需进行本机构建与启动检查。具体检查结果记录在 Release 说明中。**目前没有覆盖全部 Mac 机型的硬件测试矩阵；特别是 Intel 与不同代 Apple Silicon 的写入能力仍需逐机验证。**

SMC 没有面向第三方的稳定公开协议。本项目对未知或失败的读取明确返回不可用；不会展示随机读数假装硬件兼容，不会通过加载来源不明的驱动扩展来绕过限制。代码签名或管理员权限也无法使固件不支持的操作变得可用。

| 日期 | 硬件 / 系统 | 实际结果 | 未验证 |
| --- | --- | --- | --- |
| 2026-11-16 | Mac18,1 · Apple M6 · macOS 27.0 | `--diagnose` 读到 145 个温度传感器、1 个风扇，风扇当前 RPM、硬件最小 / 最大范围和自动模式均有实际读数 | 未安装助手，未进行任何特权风扇写入；Intel 与其他 Mac 机型未实机验证 |

## 控制保护的局限

- 固定转速限制在硬件报告的可用范围，并具有至少 1200 RPM 的软件下限；零转速、异常范围和不存在的风扇不能当作有效控制目标。
- 助手维护约 12 秒的租约。应用停止续约后尝试恢复自动控制，计时不依赖应用 UI。
- 传感器无法验证或温度达到保护阈值时停止或拒绝手动控制。
- 助手在写入前把所控制的风扇 ID 记入 root 拥有的恢复日志；launchd 重启后先尝试恢复，成功后更新日志。卸载若仍有未恢复记录会保留文件并退出。
- 退出、卸载和超时的恢复属于尽力操作，必须由 SMC / 固件接受才能生效。断电、系统挂起、助手被强制杀死或内核调用阻塞可能影响时间和效果。
- 请不要同时运行多个风扇控制器，否则它们可能互相覆盖控制模式。使用另一工具前先恢复 Apple 自动并停用本项目的控制助手。

## 提交兼容性报告

请提供 Mac 型号、芯片、macOS 版本、应用版本，以及「只读」或「已安装助手」的状态。使用应用导出诊断或运行 `MacControlPro --diagnose`，检查隐私后附在 issue。不要上传序列号、账号或完整系统报告。

收到可重复的真实机型验证后，再把该机型加入经验证矩阵；未收集到的数据不写为已验证。
