# 路线图

## 0.1：可审查、可构建的首发

- 原生 SwiftUI 总览、会话图表、传感器浏览与风扇操作。
- 明确区分真实数据、不可用数据与演示数据。
- 独立的助手、受限命令、租约与热保护。
- 完整源码、核心测试、通用安装包、持续集成和发布工作流。

## 后续优先级

1. **硬件验证矩阵**：收集不同代 Apple Silicon、Intel MacBook、iMac、Mac mini、Mac Studio、Mac Pro 的读数与写入报告，按真实设备记录支持情况。
2. **签名发行**：配置 Developer ID 和 Apple 公证；评估系统提供的特权助手注册方式以改善安装体验。
3. **更全面的传感器映射**：按机型识别 SMC key，提升命名与分组，严格过滤无效值。
4. **持久历史与比较**：本地可控的数据保留、更完整的 CSV 分析和配置前后对比，提供明确的存储与隐私设置。
5. **自动化规则**：在现有供电变化规则之上，增加负载触发与更细的条件规则，具有可查看的触发原因与随时回到 Apple 自动的入口。
6. **无障碍与国际化**：VoiceOver、键盘流程、高对比度与更多语言的实机检查。

以上是方向，未完成项目不会显示成已经支持。硬件安全与兼容性验证先于增加写入能力。
