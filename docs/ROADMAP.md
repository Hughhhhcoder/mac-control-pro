# 路线图

## 0.2.0 已实现

- 原生监控界面、菜单栏、会话图表、传感器浏览、诊断与导出。
- 按每只风扇的实际范围与控制键探测能力，区分无风扇、读取失败和只读状态。
- 双风扇、受保护模式和桌面低转速路径；百分比预设及旧配置兼容。
- P2 会话所有权、确认状态、续约、释放与恢复逻辑。
- 通用完整 PKG，以及应用内置的原生助手安装、更新和卸载入口。
- 核心、协议、模拟硬件、界面状态与安装包结构的自动化回归。

已实现路径与真实机型验证分别维护。已有物理调速记录为 0.1.1 的 M6，其他型号不会因通过模拟测试就被列为实机通过。

## 优先验证

1. **实机矩阵**：补充 M4 Pro 等双风扇 MacBook、Mac mini、Mac Studio、其他 Apple Silicon 与 Intel；记录系统版本、助手协议、实际 RPM 和恢复结果。
2. **安装与升级矩阵**：验证不同账户、旧版助手、同版本重装、升级失败和完整应用包恢复，保留安装与控制能力的区别。
3. **系统版本与生命周期**：补充 macOS 14 及其他支持系统的运行记录，覆盖睡眠唤醒、后台运行与故障恢复。
4. **签名发行**：配置 Developer ID Application、Developer ID Installer 和 Apple 公证。

## 后续能力

- 更准确的机型传感器命名与分组，继续区分通用 key、虚拟值及真实物理读数。
- 用户可控的本地历史保留、跨会话比较和数据清理。
- 在供电切换规则之外增加可查看触发原因的条件规则。
- VoiceOver、键盘、高对比度与更多语言的实机检查。

尚未完成的项目不作为当前支持承诺。兼容性结论以 [矩阵](COMPATIBILITY.md) 和 [硬件记录](HARDWARE_VALIDATION.md) 为准。
